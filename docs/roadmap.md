# 開発ロードマップ

## Phase 1 — 手動採寸 MVP（現在）

**目的**: 採寸フローを確立し、データ蓄積を開始する

**機能**:
- 犬情報登録（名前・犬種・体重）
- 画像アップロード（Supabase Storage）
- 採寸マット利用（グリッド・スケール手動設定）
- 2点クリックによる手動採寸
- 採寸データ保存（Supabase DB）
- JSON エクスポート

**スタック**: Next.js + Supabase（AI/Backend なし）

**完了条件**:
- 犬を登録 → 画像アップロード → スケール設定 → 採寸 → JSON ダウンロードの一連フローが通る
- Supabase DB にデータが正しく蓄積される

---

## Phase 2 — 採寸マット自動認識

**目的**: スケール設定を自動化し、採寸の再現性を高める

**機能**:
- ArUco マーカー自動検出（OpenCV）
- カメラ歪み補正（透視変換）
- cm 座標の自動生成

**追加技術**: FastAPI + OpenCV

**追加テーブル**: なし（measurement_sessions の pixels_per_cm を自動設定）

---

## Phase 3 — 犬キーポイント推定

**目的**: 採寸点の自動候補表示でユーザー負荷を軽減する

**機能**:
- 犬の骨格キーポイント推定（MMPose / Animal Pose）
- 採寸候補点を canvas にオーバーレイ表示
- ユーザーが候補点を確認・修正

**取得ポイント**:
鼻 / 首 / 肩 / 背中上端 / 胸下 / 腰 / 尻尾付け根 / 前足先 / 後足先

**追加テーブル**: `keypoints`（session_id, keypoint_name, x, y, confidence, source）

---

## Phase 4 — DeepLabCut 専用モデル

**目的**: 自社データで学習した高精度モデルによる採寸精度向上

**機能**:
- Phase 1〜3 で蓄積した手動採寸データを学習データとして活用
- 犬種差・体型差に対応した専用キーポイント定義
- モデルバージョン管理

**必要データ量**: 犬 100 頭以上の採寸データを目安とする

---

## Phase 5 — 動画歩行解析

**目的**: 静止画だけでは取得できない歩行状態を評価する

**取得指標**:
- 歩幅 / 歩行周期
- 左右差
- 背中の上下動
- 足の引きずり検出

**追加テーブル**: `gait_analyses`（session_id, video_url, stride_cm, cycle_sec, asymmetry, drag_detected, ...）

---

## Phase 6 — 車椅子適合評価

**目的**: 車椅子の適合度を客観的な数値で示す

**機能**:
- 重心位置の推定
- 姿勢安定スコア
- 予測歩行改善率

**追加テーブル**: `wheelchair_fit_evaluations`

---

## Phase 7 — 車椅子サイズ推薦

**目的**: 蓄積データから最適サイズを自動提案する

**入力**: 犬種 / 体重 / 採寸値 / 歩行状態
**出力**: 推奨車椅子サイズ・フレーム寸法

**追加テーブル**: `wheelchair_recommendations`

---

## Phase 8 — 車椅子設計支援（メーカー向け）

**目的**: 採寸・評価データをもとに設計仕様を自動生成する

**出力**:
- 推奨フレーム寸法
- 推奨車輪位置・径
- CAD 出力（DXF / STEP 形式）

---

## データ蓄積方針

全フェーズを通じて以下を必ず保存する:

| データ | 保存先 | 目的 |
|---|---|---|
| 元画像 | Supabase Storage | Phase 3/4 再学習 |
| 元動画 | Supabase Storage | Phase 5 解析 |
| 手動採寸クリック座標 | measurements.point_a/b | Phase 4 学習 |
| AI 推定キーポイント | keypoints.source='ai' | Phase 4 比較 |
| 手動修正後座標 | keypoints.source='human' | Phase 4 正解ラベル |
